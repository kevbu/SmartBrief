# QA: Cluster Detail Language Consistency

## Test scope
All acceptance criteria are runtime/UI behavioral checks. The project has no React component test infrastructure (only one pure-function Jest file). No e2e framework is configured.

## Acceptance criteria status

| # | Criterion | Verdict | Notes |
|---|-----------|---------|-------|
| 1 | German cluster shows German bullets | ✅ CODE | `topStory.bullets` (German) are set directly — no re-fetch |
| 2 | English cluster shows English bullets | ✅ CODE | Same path, bullets already English |
| 3 | No loading skeleton flash | ✅ CODE | `setBullets` called synchronously before `fetchBullets()` is even defined; `setLoading` never called |
| 4 | Single-article detail unaffected | ✅ CODE | Short-circuit only fires when `topStory` is set; article path is unchanged |
| 5 | Cluster without bullets falls back to fetch | ✅ CODE | Guard is `topStory.bullets.length > 0`; empty array falls through to existing fetch |

## Manual verification checklist
- [ ] Open app, tap a German-source cluster → bullets should be in German
- [ ] Open app, tap an English-source cluster → bullets should be in English
- [ ] No spinner/skeleton visible when opening a cluster with bullets
