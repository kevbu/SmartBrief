# Spec: Cluster Detail Language Consistency

## Approach
In `ArticleDetail`, when the component opens for a `topStory` that already has bullets, use those bullets directly. The TopStory's bullets were generated by `generateTopStories()` with a language rule ("if majority of article titles are German, write everything in German"). No API, DB, or schema changes are needed.

## Root cause
`ArticleDetail.useEffect` always calls `GET /api/articles/${ids[0]}?topStoryId=...` when a topStory is selected. That endpoint generates article-level bullets with the prompt "Generate exactly 3-5 concise bullet points summarizing this news article" — no language instruction — so the model defaults to English regardless of the article's language.

## File to change
**`src/components/ArticleDetail.tsx`** — the `useEffect` that fetches bullets

## Implementation steps

### 1. Short-circuit the fetch for topStories with bullets

In the `useEffect`, add a branch before `fetchBullets()`: if `topStory` is set and has non-empty bullets, set them directly and return without fetching.

Current logic (lines 28–66):
```ts
useEffect(() => {
  setBullets([])
  if (!article && !topStory) return

  async function fetchBullets() {
    // ...
    if (article) { /* fetch article bullets */ }
    else if (topStory) {
      // fetches /api/articles/${ids[0]}?topStoryId=...
    }
  }
  fetchBullets()
}, [article, topStory])
```

New logic:
```ts
useEffect(() => {
  setBullets([])
  if (!article && !topStory) return

  // Use pre-generated cluster bullets if available (already language-correct)
  if (topStory && topStory.bullets && topStory.bullets.length > 0) {
    setBullets(topStory.bullets)
    return
  }

  async function fetchBullets() {
    // unchanged — only runs for articles or topStories without bullets
    if (article) { /* ... */ }
    else if (topStory) { /* ... */ }
  }
  fetchBullets()
}, [article, topStory])
```

That's the entire change. No other files are affected.

## Acceptance criteria

1. Opening a German-language cluster detail sheet shows bullets in German
2. Opening an English-language cluster detail sheet shows bullets in English
3. The loading skeleton does not flash before bullets appear (bullets are set synchronously)
4. Single-article detail sheets are unaffected
5. Clusters that have no bullets fall back to the existing fetch behavior (no regression)
