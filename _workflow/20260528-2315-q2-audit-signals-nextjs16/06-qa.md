## Issues Found and Fixed

### Issue 1 — Stray `text-gray-400` in page.tsx

- **Where:** `src/app/page.tsx` line 678 — `<LoadingSpinner size="sm" className="text-gray-400" />`
- **Expected:** `text-slate-400` (consistent with slate palette)
- **Fix applied:** Changed to `text-slate-400`
- **Severity:** Minor (visual inconsistency, same perceived color)

### Issue 2 — No explicit focus-visible states

- **Where:** All components — no `focus-visible:` utility classes; no `outline-none` present either, so browser defaults were technically intact but inconsistent across browsers
- **Expected:** Consistent, designed focus ring (design system checklist: "Focus states visible for keyboard navigation")
- **Fix applied:** Added CSS base rule to `globals.css`:
  ```css
  :focus-visible {
    @apply outline-none ring-2 ring-blue-500 ring-offset-2 ring-offset-white dark:ring-offset-slate-950;
  }
  ```
  This applies a consistent blue ring to all keyboard-focused elements in both light and dark mode without requiring per-element changes.
- **Severity:** Minor (personal app, primarily touch-driven; browser defaults were present but inconsistent)

## Deliberate Non-Issues (Annotated)

- **`shadow-sm` in TopicTabs, MoodPresetToggle, depth toggle** — these are on inner segmented control active pills, not card surfaces. The design system explicitly allows `shadow-sm` in this context.
- **`bg-gray-400` in BiasBadge** — intentional: represents "center" political bias as a neutral gray. Documented in design system as acceptable.
- **`shadow-lg` on FeedbackMenu tooltip** — floating element, not a card. Shadow on floating UI is correct.
- **No `cursor-pointer` on `<a>` tags in ArticleDetail** — native anchor elements have pointer cursor by default; adding `cursor-pointer` would be redundant.
- **`alt=""` on article thumbnails** — correct WCAG 2.1 practice for decorative images. Screen readers correctly skip them.
- **Secondary pages (settings, saved, recap) still use `gray-*` tokens** — documented in design system migration table; out of scope for this overhaul.
