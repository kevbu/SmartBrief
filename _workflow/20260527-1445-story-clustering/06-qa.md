## Edge Cases and Risks

| Risk | Severity | Notes |
|------|----------|-------|
| `bullets` is `[]` (empty array from Claude) | Low | `story.bullets.length > 0` check handles this → fallback to summary |
| `clusterArticles` URLs are newsletter:// protocol | Low | `href` links with non-http URLs won't open in a tab but won't crash — acceptable edge case |
| All articles are clustered (no unclustered items) | Low | `articleList.filter(a => !clusteredIds.has(a.id))` returns `[]` → no ArticleCards shown after clusters — correct |
| `sources.length` sort stability | Low | `.sort()` is stable in V8; equal-length clusters retain DB order (by createdAt desc) — acceptable |
| 12h window returns 0 articles, fallback fires | Low | Fallback to `take: 100` prevents empty clustering input — covered |
