2. API fixture (`qa-api.db`): production build via `next start -p 3101`. Seed:
   - Prefs: `hiddenSources = "Bild"`, `avoidTopics = "bitcoin"`.
   - Current batch: `c-hidden` (sources Bild, BILD), `c-mixed` (Bild, Reuters), `c-topic` (title "BITCOIN rally continues"), `c-ok` (BBC, Reuters; its only article is from Bild, so filtered out of the article list), `c-nosrc` (no sources).
   - Saved: articles `a1` (savedAt null, newest publishedAt), `a2` (savedAt yesterday); stories `s-legacy` (savedAt null), `s-dated` (savedAt set).
